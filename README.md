# EDIREG – Educational Integration of Refugee Children and Youth in Germany

Archive website of the BMBF junior research group **EDIREG** (2021–2026, grant no. 01JG2107).

The site is plain HTML/CSS and is published with GitHub Pages.

| File | Page |
|---|---|
| `index.html` | Main |
| `overview.html` | Background and goals |
| `publications.html` | Publications, talks, press, theses |
| `team.html` | Team |
| `impressum.html` | Impressum |
| `style.css` | Layout and colours |
| `images/` | Logo, funding logos, poster, team photo |

To change text, open a file on GitHub, click the pencil icon, edit, and click **Commit changes**. The live site updates after about a minute.
